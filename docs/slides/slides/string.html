制御系として見る 2

1台は安定、列は不安定

G(p) =

λp + aV′

p² + (a + λ)p + aV′

前の車の速度から自分の速度への伝達関数。全員が同じ車間で走る状態のまわりで線形化しました。V′ は S 字の傾き、p はラプラス変数です。

1台ずつは、必ず安定

極は p² + (a+λ)p + aV′ = 0 の根。a, λ, V′ が正なら左半平面にあります。どの1台も、前の車に追従できます。

つなぐと、不安定になりうる

n 台後ろの速度は G(p) を n 回かけたもの。|G(jω)| が 1 を超える周波数があると、その成分は後ろへ行くたびに大きくなります。

列安定性の条件

|G(jω)| ≤ 1 （すべての ω）　⇔　V′ ≤ a/2 + λ

線形化すると、前の車の速度から自分の速度への伝達関数はこの2次系になります。分母の極は、a, λ, V′ が正なら必ず左半平面にあります。つまり1台ずつ見れば、どの運転者も前の車にちゃんと追従できる、安定な制御系です。ところが、この G を直列に何十個もつなぐと話が変わります。ある周波数で G のゲインが1を超えていれば、その成分は後ろへ行くたびに大きくなる。これを列安定性、string stability と呼びます。ゲインの式を計算すると、条件は V′ が a/2 + λ 以下、というきれいな形になります。22台・a=1.5 では V′ = 1.74、a/2+λ = 1.15 なので条件を破っています。
