自然渋滞の実験室

事故も工事も合流もないのに起きる渋滞を、運転者を「制御器」とみなした数式モデルで動かします。実験1は2008年の円形コース実験と同じ周長と台数、実験2は日本の高速道路で渋滞の先頭になりやすいサグ部（下り坂から上り坂に変わる凹部）です。後半では、モデルの立て方と、制御工学から見た不安定のしくみを説明します。

30秒でわかる自然渋滞

  1. 前の車が減速すると、後ろの車は少し遅れて、ほんの少し強めに減速しがちです。
  2. その「少し」が後ろの車へ次々に積み重なると、どこかで止まる車が出ます。
  3. 止まる場所は少しずつ後ろへ移るので、渋滞の先頭へ行っても原因は見当たりません。

下の実験1で、自分でブレーキを踏んで確かめられます。図はしくみのイメージです。

実験 2

試し方

  4. Δs を 0 にする車間の感覚がずれなければ、坂の外乱だけではほとんど渋滞しません。理由は後半の「サグ部のモデル」で。

なぜ原因なしに渋滞が起きるのか

ブレーキは後ろへ強まって伝わる

ひとことで後ろの車ほど、少し遅れて、少し深く減速します。その「少し」が積み重なります。

前の車のブレーキランプが光ってから、自分が速度を合わせ終わるまでには少し時間がかかります。そのあいだにも車間は縮むので、追いつくころには前の車より少し強く減速しないと間に合いません。すぐ後ろの車も同じ理由で、さらに少し強く減速します。

（計算中）

渋滞のかたまりは後ろへ進む

ひとことで車は前へ進んでも、止まっている場所は後ろへ動きます。

渋滞の先頭では、前が空いた車から順に発進して抜けていきます。最後尾には、後ろから来た車が次々に加わります。どの車も前へ進んでいるのに、止まっている場所そのものは後ろへずれていきます。時空図で車の軌跡が右上がり、赤い帯が右下がりなのはこのためです。実験1のモデルでは、帯は （渋滞ができると表示） で後ろへ動いています。

消えるか育つかは、車間と反応で決まる

ひとことで車間に余裕があるか、反応がすばやければ、ゆれは消えます。

車間に余裕があれば、前の車が減速しても慌てずに済み、減速は後ろへ行くほど浅くなります。車間が詰まっていて反応がのんびりしていると、上乗せのほうが勝ちます。実験1の「育つか消えるかの境目」の図で、色の付いた領域が育つ側です。1周230mに22台（車間およそ6.5m、時速30km）は、反応が a = 1.5 /s ならこのモデルでは育つ側に入ります。台数を減らすか、反応をきびきびさせると、消える側へ移ります。

2008年の円形コース実験

ひとことで本物の車22台でも、ボトルネックなしで渋滞が起きました。

渋滞は、合流やトンネルのようなボトルネック（ほかより通れる台数が少ない場所）がなくても起きます。これを実際の車で確かめたのが、杉山雄規・西成活裕らのグループの実験です。1周230mの円形コースに22台の乗用車を並べ、運転手には時速30kmで走るよう頼みました。はじめはそろって走れていた列に、やがて速度のむらが生まれ、数台が一時止まるかたまりができて、それが後ろへ進んでいきました。論文は、ボトルネックは渋滞のきっかけにすぎず、本当の原因ではないと述べています。実験2のサグは、まさにそのきっかけの役をします。

モデル化

ひとことで本物の交通から、渋滞を説明するのに要るものだけを残して、計算できる式にします。

このページの結果は、どんなモデルを置いたかで決まります。何を残し、何を捨て、どの数値を選んだかを順に書いておきます。

  1. 見たいものを決める。知りたいのは「1台の小さな減速が、列を伝わるうちに育つか消えるか」です。そこで、車線変更・追い越し・信号・車種の違いは捨て、1車線を走る車の列だけを残します。
  2. 状態を選ぶ。n 番目の車の位置 xn と速度 vn を状態にします。前の車（n+1 番目）との車間は sn = xn+1 − xn − ℓ（ℓ は車の長さ）。N 台なら 2N 個の状態です。
  3. 車を書く（制御対象）。車は「加速度を指令すると速度が変わり、速度で位置が変わる」二重積分器とみなし、エンジンやブレーキの応答の遅れは省きます。
    dxn/dt = vn,　　dvn/dt = un + dn
    un は運転者が決める加速度、dn は坂などの外乱（運転者が決められない外からの力）です。
  4. 運転者を書く（制御器）。運転者は、車間と相対速度を見て加速度を決めます。
    un = a [ V(sn) − vn ] + λ ( vn+1 − vn )
    V(s) は「車間が s のときに出したい速度」、a はその速度へどれだけすばやく合わせるか、λ は前の車との速度差にどれだけ反応するかです。前半は最適速度モデル（坂東昌子ら, 1995）、相対速度の項を足した全体は FVD モデル（Jiang ら, 2001）と呼ばれます。
  5. V(s) の形を決める。車間が詰まれば止まり、十分空けば上限の速度で頭打ちになり、その間はなめらかにつながる S 字にします。
    V(s) = Vmax tanh((s − s0 − sc)/w) + tanh(sc/w)1 + tanh(sc/w)　（s > s0、それ以外は 0）
    傾きがいちばん急なのは中ほどの車間で、ここが渋滞しやすい密度になります。
  6. 制約を足す。加速は 3 m/s² まで、減速は 9 m/s² まで、速度は 0 以上。前の車に速く近づいているときは、追突しないのに必要な減速度に応じて、なめらかにブレーキを強めます。これらは線形解析（小さなずれだけを考えて式を簡単にする調べ方）には出てきませんが、育った波が「止まる」ところまで行ったときの形を決めます。
  7. 数値を決めて、確かめる。下の表の値は、1周230mに22台で時速30kmになり、2008年の実験のように渋滞が出るよう選びました。渋滞の帯が後ろへ進む速さは、このモデルでは （実験1で渋滞ができると表示）。実際の高速道路では時速15km前後（およそ10〜20km）と報告されていて、このモデルはやや速めです。
  8. 限界を書いておく。反応のむだ時間を入れていない、全員が同じ性格、1車線だけ、といった単純化があります。数値は実験の再現ではなく、しくみを見るためのものです。

制御系として見る

ひとことで運転者は「車間を見てアクセルとブレーキを調整する制御器」です。制御工学の道具を使うと、渋滞が育つ条件を式で書けます。

モデルをブロック線図（信号の流れを箱と矢印で描いた図）にすると、運転者は「車間から目標速度 V(s) を作り、速度の誤差を P 制御（ずれに比例した強さで直す制御）で詰め、相対速度（車間の微分）にも反応する」制御器です。車はその出力を積分する制御対象です。前の車の速度が入力、自分の速度が出力で、自分の速度は次の後ろの車の入力になります。

線形化と伝達関数

ひとことで前の車の速度が少しゆれたとき、自分の速度がどうゆれるかを、1本の式にまとめます。

全員が同じ車間 s* と速度 V(s*) で走る状態（平衡点）のまわりで線形化します。V′ を平衡点での傾きとすると、前の車の速度から自分の速度への伝達関数は次の2次系です。

G(p) = Vn(p)Vn+1(p) = λp + aV′p² + (a + λ)p + aV′

1台は安定、列は不安定

ひとことで1台ずつはきちんと前の車についていけます。それでも、ゆっくりした速度のむらは1台通るごとに少しずつ大きくなります。

G(p) の極は p² + (a+λ)p + aV′ = 0 の根で、a, λ, V′ が正なら必ず左半平面にあります（左半平面にあれば、ゆれはやがて収まります）。どの1台も、前の車に安定に追従します。問題は、この G を何十台も直列につないだときです。n 台後ろの車の速度は G(p)n 倍になるので、ある周波数で |G(jω)|（その周期のゆれが1台で何倍になるか、ゲイン）が1を超えると、その成分は後ろへ行くたびに増えます。列安定性（string stability）の条件は、すべての ω で |G(jω)| ≤ 1 です。

計算すると |分母|² − |分子|² = ω²(ω² + a² + 2aλ − 2aV′) なので、条件は次の形になります。

V′(s*) ≤ a/2 + λ　（破れると不安定）

破れると、0 < ω < ωc = √(2aV′ − a² − 2aλ) のゆっくりした速度変化が増幅されます。急なブレーキそのものより、数秒周期のゆるやかな速度のむらのほうが危ないということです。いまの実験1の設定では V′ = 1.74 /s, a/2 + λ = 1.15 /s。

円形コースはフィードバックループ

ひとことで円形コースでは、波が一周して自分に戻ってきます。戻るたびに大きくなれば渋滞になり、途中で1台が波を吸い取れば消えます。

円形コースでは、最後の車の前に最初の車がいます。G を N 個直列につなぎ、出口を入口へ戻したループです。特性方程式は G(p)N = 1 で、一周のゲイン |G(jω)|N が1を超える帯域があると、そこに位相の合う速度のむらが周回のたびに大きくなります。実験1の棒グラフで、2周目・3周目の棒がさらに低くなるのはこのためです。

渋滞吸収車は、このループにローパスフィルタ（ゆっくりした変化だけを通し、速い変化をならすもの）を1個入れることに当たります。吸収車は前の車の速度を20秒かけて平均し、それにゆっくり合わせます。伝達関数は

Gav(p) = 0.4(20p + 1)(p + 0.4)

増幅される帯域でのゲインはとても小さく、ほかの車ぶんの増幅を打ち消して余ります。一周のゲインが1を下回るので波は育ちません（小ゲイン定理の考え方。全員が同じだけずれる ω = 0 の動きは除きます）。

線形解析の外側

ひとことで式で分かるのは「育ち始めるか」まで。育ったあとの、止まる車のかたまりの形はシミュレーションで見ます。

線形化で分かるのは、波が育ち始めるかどうかまでです。育った波は、速度が 0 より下がらない、上限で頭打ちになる、という飽和で振幅が止まり、止まる車のかたまり（ジャムクラスタ）として一定の形で周回します。リミットサイクル（同じ形の振動がくり返し続ける状態）に近いものです。

反応のむだ時間 τ（反応が始まるまでの遅れ）を入れると、分母の p² が p²epτ になります。ω が小さいところの条件は変わりませんが、中ほどの周波数で |G| が1を超えやすくなり、列はさらに不安定になります。このページのモデルにはむだ時間を入れていません。

サグ部のモデル

ひとことでサグでは、気づかないうちに上り坂で遅くなり、車間も広がります。そのぶん上り坂を通れる台数が減ります。

NEXCO東日本は、サグ部を「下り坂から上り坂に変化する、無意識のうちに速度が低下しやすいポイント」と説明し、年末年始の渋滞予測でも多くの渋滞ポイントの原因に「サグ部等での速度低下」を挙げています。

Goñi-Ros らは、東名高速道路のサグで撮影した車の軌跡などから、サグでは速度が落ちるうえに、速度の割に車頭時間（前の車が通ってから自分が通るまでの時間）が長くなることを示しています。その結果、通れる台数が通常の区間より少なくなります（最大で3割ほどという報告もあります）。原因は、上り坂の抵抗をアクセルの踏み増しで補いきれないことだとされています。

そこで実験2では、上り坂の区間で運転者の式に二つの項を足しました。

un = a [ V(sn − Δs·h(xn)) − vn ] + λ ( vn+1 − vn ) + ξn,　　dn = −(1 − κ) g θ(xn)
  • θ(x)：勾配。下り −4% から上り +4% へなめらかに変わります。g = 9.8 m/s²。
  • κ = 0.5：運転者がアクセルの踏み増しで補う割合。残りの (1 − κ)gθ が外乱として車に入ります。
  • h(x)：上り坂の度合い（0〜1）。Δs：上り坂で車間の感覚が広がる量。同じ車間でも出したい速度が下がります。
  • ξn：運転のゆらぎ（±0.4 m/s² の一様乱数）。

外乱と目標の変化は、制御では別物

ひとことで坂で車が押し戻される分は、運転者がすぐに取り返せます。取り返せないのは、上り坂で「これくらい空けたい」と感じる車間が広がることです。

勾配の項は外乱 d です。運転者の速度ループは P 制御なので定常偏差（最後まで残るずれ）が残り、その大きさは (1 − κ)gθ/a = 0.13 m/s（0.5 km/h） です。このモデルでは、坂の外乱そのものはフィードバックでほとんど打ち消されます。

Δs の項は外乱ではなく、目標（V(s) という参照）の変化です。平衡点そのものが動き、上り坂で流せる最大の交通量（容量）が下がります。いまの設定では Δs = 3.0 m → 平坦な道の 80 % です。ループの外側の変化なので、ゲイン a を上げても直りません。実験2で Δs を 0 にするとほとんど渋滞しないのはこのためです。

渋滞の先頭がサグに居座るわけ

ひとことで上り坂を通れる量より多く車が来ると、あふれた分がサグの手前にたまります。たまった所では、実験1と同じしくみで止まる波が生まれます。

入る交通量が上り坂の容量を超えると、超えた分の車がサグの手前にたまります。たまった区間は車間が詰まり、V′ が大きい、つまり列安定性の条件を破る領域に入ります。そこで小さなゆらぎが増幅され、止まる波になって上流へ出ていきます。先頭はボトルネックになった上り坂に固定され、波だけが後ろへ進みます。サグを抜ける量も、容量より少し下まで落ちます。

開いた道路では、波は上流へ流されながら育ちます（対流不安定）。円形コースと違って同じ場所に戻ってこないので、育つには種になるゆらぎが絶えず要ります。実験2で運転のゆらぎを常に入れているのはこのためです。

サグの対策を制御の言葉で

ひとことで坂を知らせる、車間の感覚を自動で保つ、来る量を減らす、の3つがあります。

  • 速度回復の呼びかけ（看板・ナビの音声）。運転者に坂を知らせるフィードフォワードです。κ を上げ、Δs を小さくする方向に働きます。NEXCO東日本も上り坂・サグ部で速度回復への協力を呼びかけています。
  • ACC（車間を時間で保つ自動追従）。坂でも目標の車頭時間を変えなければ Δs は生じず、速度ループに積分動作（ずれを積み上げて、残ったずれも消す働き）があれば勾配の外乱による定常偏差も残りません。
  • 可変速度制限。上流で速度を絞り、サグに入る交通量を上り坂の容量以下に保ちます。流入量を操作量にした制御です。

円形コースの渋滞はどうすれば防げるか

ひとことで車間を空ける、前の車にぴったり合わせない、の2つが基本です。

  • 車間を空ける。V(s) の傾きがゆるい所で走ることになり、条件 V′ ≤ a/2 + λ を満たしやすくなります。
  • 前の車にぴったり合わせない。前が減速しても、車間を少し縮めて速度を保てば、後ろへ伝わる波は小さくなります。いわゆる渋滞吸収運転で、制御の言葉では増幅帯域のゲインを下げることです。
  • 1台の自動運転車でも効く。Stern らの2018年の実験では、20台あまりが走る円形コースで、1台の自動運転車の速度をこの考え方で制御しただけで、停止と発進をくり返す波が消えました。実験1の「渋滞吸収車」は、この考え方を単純にまねた1台です。

このページの車は上の式で動いています。数値は2008年の実験や実際のサグを再現したものではなく、しくみを見るためのものです。実験1で「運転のゆらぎ」がOFFのあいだは、誰かがブレーキを踏まない限り、列はそろったまま走り続けます。

用語集

時空図
横軸に時間、縦軸に道路上の位置をとり、各車の位置を点で打った図。車の動きと、渋滞の帯の動きを一度に見られます。
ボトルネック
道路の中で、ほかより通れる台数が少ない場所。合流部、トンネルの入口、サグなどです。
外乱
制御する側が決められない、外からの力や変化。ここでは上り坂で車が押し戻される力です。
P 制御
目標とのずれに比例した強さで直す制御。ここでは「出したい速度」と今の速度の差に比例して加速・減速します。
線形化・平衡点
全員が同じ車間・同じ速度で走る状態が平衡点です。そのまわりの小さなずれだけを考え、式を比例の関係に直すことを線形化といいます。
伝達関数
入力（前の車の速度）がゆれたとき、出力（自分の速度）がどうゆれるかを、ゆれの速さ（周波数）ごとに表した式です。
ゲイン
ある周期のゆれが、1台を通るあいだに何倍になるか。1より大きければ増え、1より小さければ減ります。
列安定性
車の列を伝わるあいだに、どの周期のゆれも大きくならない性質。英語では string stability。1台ずつの安定とは別の性質です。
小ゲイン定理
ループを一周したゲインが1より小さければ、ゆれは育たないという定理です。
定常偏差
制御を続けても最後まで残る、目標とのずれ。P 制御で坂のような一定の外乱を受けると残ります。
フィードフォワード
外乱が来ることを前もって知り、ずれが出る前に操作すること。看板で坂を知らせ、先にアクセルを踏んでもらうのがこれに当たります。
対流不安定
ゆれが育ちながら、同じ場所にとどまらずに流されていく不安定さ。開いた道路の渋滞の波は、上流へ流されながら大きくなります。
