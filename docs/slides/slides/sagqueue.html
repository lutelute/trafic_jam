サグ部の渋滞

来る量が通れる量を超えると、手前にたまる

来る量

95 %

上り坂で通れる量（Δs = 3 m）

80 %

実際にサグを抜けた量（計算）

約 81 %

差の約 15 % がサグの手前にたまります。渋滞の先頭はサグに固定され、止まる波だけが上流へ出ていきます。

割合は、平坦な道で流せる最大量に対する値。坂がなければ、同じ 95 % でもそのまま流れます。

実験2のモデルで、交通量を平坦な道の95%にしたときの計算です。右は道路の時空図で、縦が位置、横が時間、帯がサグです。上り坂で通れる量は Δs=3m のとき80%なので、95%が来ると差の15%が手前にたまっていきます。サグを実際に抜けた量は約81%で、通れる量の上限に張り付きます。たまった区間は車間が詰まり、列安定性の条件を破る密度に入るので、ゆらぎが育って止まる波になり、上流へ出ていきます。坂がなければ、同じ95%でもそのまま流れます。
