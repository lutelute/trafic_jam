円形コース＝ループ

G を N 個つないで出口を入口に戻したループ。特性方程式は G(p) の N 乗 = 1。一周のゲインが 1 を超える帯域があると、そこに合う速度のむらが周回のたびに大きくなります。

吸収車＝ローパスフィルタ

G av(p) = 0.4 / ((20p + 1)(p + 0.4))

前の車の速度を20秒かけて平均し、ゆっくり合わせる。周期7秒でのゲインは 0.02 で、残り21台の増幅 3.5 倍を打ち消して余ります。

円形コースでは最後の車の前に最初の車がいるので、G を22個つないで出口を入口に戻したフィードバックループになります。一周のゲインが1を超える帯域があると、その速度のむらは周回のたびに育つ。さっきの棒グラフで2周目、3周目と深くなったのはこれです。渋滞吸収車は、このループにローパスフィルタを1個入れることにあたります。前の車の速度を20秒かけて平均し、それにゆっくり合わせる。周期7秒でのゲインは0.02しかないので、残り21台ぶんの増幅3.5倍をかけても0.07。一周のゲインが1を下回るので波は育ちません。Stern らの2018年の実験では、20台あまりの円形コースで、1台の自動運転車の速度制御だけで停止と発進の波が消えています。
